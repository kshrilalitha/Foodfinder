# 🍛 Karnataka Local Food Finder

A collaborative Python Django web application developed to help users discover authentic Karnataka cuisine based on region and category. The platform showcases traditional dishes, detailed descriptions, and restaurant recommendations, making it easy to explore Karnataka's rich culinary heritage.

---

## 📌 Features

- 🍽️ Browse authentic Karnataka dishes
- 🔍 Search dishes by name
- 🗂️ Filter dishes by category and region
- 📖 View detailed information about each dish
- 📍 Explore restaurants serving traditional dishes
- 📱 Responsive and user-friendly interface
- 🔐 Django Admin Panel for managing dishes and restaurants

---

## 🛠️ Tech Stack

- Python
- Django
- HTML5
- CSS3
- JavaScript
- SQLite
